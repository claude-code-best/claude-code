# Security Policy

## Supported Versions

Security fixes are applied to the latest release line only.

| Version | Supported          |
| ------- | ------------------ |
| 2.8.x   | :white_check_mark: |
| < 2.8   | :x:                |

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities. Report them privately through
[GitHub Security Advisories](https://github.com/claude-code-best/claude-code/security/advisories/new).

Include, if possible:

- affected version and platform;
- steps to reproduce or a proof of concept;
- impact and suggested remediation.

We aim to acknowledge a report within 7 days and to share a remediation timeline once the issue is
confirmed. Please keep the report private until a fix is released.

Note: this project is a reverse-engineered, educational reimplementation. All rights to Claude Code
belong to Anthropic. Security reports about the upstream product should go to Anthropic directly.
